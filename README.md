# AI Classroom
Static Next.js app (`output: "export"`). Keys live in your browser's localStorage only.
## Free deploy (browser only)
1. Create a GitHub repo and upload these files (Add file → Upload files).
2. Vercel: Add New → Project → Import the repo → Deploy. (Netlify: Add new site → Import from Git; build `npm run build`, publish dir `out`.)
3. Open the site, go to Settings, paste a free Gemini key from aistudio.google.com/apikey.
## Not yet included
pdf.js PDF parsing, whiteboard (tldraw/Excalidraw), KaTeX/Mermaid, short-answer quizzes.
